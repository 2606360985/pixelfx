# 霓虹海岸 2D / Neon Coast GTA Sandbox

基于 `pixelfx` 开源像素特效库的 **2D 像素 GTA6 风格高自由度沙盒原型**，采用 **2.5D 宽大道斜俯视视角**（`480×270` 原生像素画布 + 3D 骨架角色 + 全 244 个 `pixelfx` 特效实时驱动）。

## 快速启动

```powershell
npm run gta
```

浏览器打开：`http://localhost:8080/gta/`

运行单元测试（同时不破坏原《街头双响》）：

```powershell
npm run test:gta
npm run test:game
```

## 核心操作（键盘 + 鼠标）

- `W A S D` / `方向键`：徒步移动 / 驾驶加速与上下变道（徒步按住 `Shift` 冲刺奔跑）
- `鼠标移动 + 左键`（或 `J`）：向鼠标指向释放当前装备的像素特效（**支持开车时 Drive-by 释放**）
- `鼠标右键`（或 `K`）：徒步近身重击
- `空格`：徒步跳跃 / 驾车手刹漂移甩尾
- `F`：上车 / 下车 / **抢夺路过车辆**（支持敞篷跑车、肌肉车、轿车、警车、老头乐三轮代步车、货运电三轮）
- `H`：按喇叭（汽车鸣笛 / 三轮车清脆铃声 / 警笛，路人会避让吐槽）
- `E`：与路人交谈/挑衅打架、找摊主回血补给、进入街区地标门洞切换场景
- `Q`：在 **陆川 (Rico)** 与 **霓莎 (Lumi)** 两位原创主角之间实时切换
- `1 ~ 8` / `鼠标滚轮`：切换快捷特效槽位
- `Tab`：打开 **全 244 特效技能轮盘**（覆盖 21 个大类，含核爆、黑洞引力、连锁闪电、13 种异常状态、12 种全屏天气、12 种召唤生物等）
- `M`：打开 **街区切换 & 合规 PNG 自定义背景工作室**（可切换 4 个原创街区、挑选 10 种 `transitions/*` 转场，或直接拖入本地合规像素 PNG 背景图）
