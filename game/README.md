# 街头双响 / Street Duet

原创市井像素清版动作游戏，原生 JavaScript + Canvas 2D。四选二组队，单人控制与 AI 搭档协作，战斗中随时切换。

```powershell
npm run game
```

打开 http://localhost:8080/game/ 。默认本机端口 8080，端口占用时可使用 `npm run game -- 8081`；原特效画廊仍在 `/gallery/`。

## 角色与选角

- 凌风：高瘦工装男性，长腿快攻；穿街踢 / 挑灯腿 / 回身扫 / 疾影连踢。
- 磐石：矮壮围裙男性，重拳破防；开路靠 / 落桩拳 / 震巷踏 / 震街重踏。
- 小满：24 岁成年轮滑女性，活泼快攻；滑步撞 / 跃轮踢 / 旋轮舞 / 满街流星。
- 绯绫：29 岁成年扇术女性，成熟控场；燕返扇 / 回风步 / 绯扇圆舞 / 绯影千叠。

标题页先点击主控或搭档位置，再点击角色卡。不能重复选择；默认凌风＋磐石，最近阵容与设置保存在本机。支持 Tab / Enter / 空格操作按钮；手柄十字键移动焦点，A 确认，Start 开始。手柄在 AI 选择框中用上下键调整等级。

## 战斗操作

WASD / 方向键移动，J 轻击，K 重击，空格跳跃，L 闪避，E 拾取／放下／长按救援，Q 切换，**1 / 2 / 3 小技能，U 个人终极技，I 接力／双人合击／杂兵终结**，Esc 暂停。画面下方两组四格技能栏显示各角色状态，可点击当前主控的就绪技能。

标准手柄：左摇杆／十字键移动，X / Y / A / B 对应轻击／重击／跳跃／闪避，LB 互动、RB 切换、RT 协作、Start 暂停。**按住 LT，再按 X / Y / B 发动小技能，LT＋A 发动终极技**。组合输入不会同时触发普通动作，单独 LT 不发动技能。失焦或手柄断开会暂停。

J 连按三次普通连招，J / J / K 变招；闪避后攻击发动突进，跳起攻击发动空中招式。轻击在命中后的衔接窗口输入，长按不自动连击。靠近失衡杂兵按 K 抓取，J 追加、K 投掷。西瓜可扔两次，折凳可挥击三次，瓜筐掉落治疗，重击推车可击倒敌人。

三个小技能分别冷却，不消耗气槽；第四格终极技消耗满气槽。技能需要空手落地且未受控，不能打断正在进行的动作。成功起手即扣除资源，落空或受击中断不退还；无效输入不会排队自动出招。切换角色保留冷却，命中停顿、暂停和合击期间冻结；重试恢复检查点阵容与冷却。

搭档 AI 分基础／熟练／高手，只有思考频率与战术判断不同，不改变数值。AI 按距离和包围情况使用小技能，不自行消耗气槽或默契槽。协作键先检查杂兵终结条件，再检查双人合击，否则请求普通接击；全部 12 种有序阵容共用这些规则。

## 美术与结构

街口以面馆、唱片行和修车铺为主，瓜摊有棚布、瓜堆、秤台与灯串，街尾以茶馆和不夜城会馆组成 Boss 舞台。远景楼群视差、分层路灯光、湿路反射、蒸汽与近景植物共同组成暖黄／青绿的复古夜市。建筑按位置独立配置，静态场景与角色姿势缓存，特效前后分层并限制同时 18 个实例。

`data.js` 配置角色、基础招式与技能；`world.js` 是固定步长独立模拟；`render.js` 处理骨架、角色换装与特效；`art.js` 绘制原创立绘、服装、配件和技能图标；`scenery.js` 缓存街区画面。命中与随机逻辑不依赖渲染。

角色的脸、发型、服装、名字、背景及所有像素立绘为代码原创绘制，仅采用宽泛体型反差和市井动作灵感；没有使用演员照片、影视截图、原片台词、配音或音乐。复用的 pixelfx 特效保留 MIT 许可证与署名。中文使用系统字体，不使用另行授权的 `gallery/fonts/Patch Pixel`；音频由 Web Audio 生成。

## 验证与视觉检查

```powershell
npm run test:game
node tools/check.mjs melee/uppercut melee/double-slash melee/spin-slash melee/heavy-cleave impacts/ground-slam impacts/heavy-landing impacts/blunt-hit impacts/crit-hit
```

逻辑与输入测试覆盖原有战斗规则、四人各技能、状态限制、冷却与检查点、AI、组合键以及 12 种阵容的整关推进。

`/game/?debug&seed=2026` 显示判定框、帧率和特效数量，反引号切换绘制，F2 充满气槽、默契并清除冷却。只有带 debug 参数时才暴露 `window.streetDuet`。

独立视觉检查页为 `/game/tests/visual.html`，可选择角色、技能、街区和定格时刻，查看 16 技能接触表与三街区总览，并进行固定 1800 帧（30 秒游戏时间）的重特效压测。报告平均／P95 同步模拟与 Canvas 提交耗时及 CPU 吞吐上限；这个上限不是实测屏幕刷新率，后台标签页的浏览器限帧不计为游戏性能。该页面不被游戏入口导入。

标准手柄通过模拟映射测试，尚未连接实体手柄试玩；实际难度、首次通关时长和不同硬件上的性能仍需真人校准。
