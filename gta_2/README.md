# 九龙雨夜：失真线 · KOWLOON NOIR: GLITCH LINE (`gta_2`)

基于 `pixelfx` 开源像素特效库的 **写实港风新黑色电影（Neo-Noir）× VN 主线剧情驱动** GTA 2D 沙盒版本：
- **全场景、角色、载具、道具与 VN 立绘/CG**：采用高清写实（`1440×810`）渲染与视觉小说演出。
- **技能特效层**：保留仓库全部 244 个 `pixelfx` 原生像素特效，以邻近采样锐利叠加在写实暴雨街头之上，形成「写实罪案都市 × 像素位元异能」强反差视效。
- **VN 主线剧情**：包含序章 + 4 章主线 + 3 种分支结局；支持随章节渐进解锁特效，或随时在顶栏一键开启「全 244 沙盒模式」。

## 快速启动

```powershell
npm run gta2
```

浏览器打开：`http://127.0.0.1:8080/gta_2/`

运行单元测试：

```powershell
npm run test:gta2
```

## 操作说明

- **VN 剧情模式**：点击对话框 / `空格` / `Enter` 推进对话；`1 / 2 / 3` 选择剧情分支；右上角支持「自动」与「跳过至抉择」；按 `V` 打开剧情档案与对话回放。
- **沙盒 / 战斗 / 驾驶模式**：
  - `W A S D` / `方向键`：移动 / 驾驶（按住 `Shift` 冲刺或氮气加速）
  - `鼠标左键` / `J`：向鼠标瞄准方向释放像素特效（支持开车 Drive-by）
  - `鼠标右键` / `K`：近身格斗
  - `空格`：徒步跳跃 / 驾车手刹漂移
  - `F`：上车 / 下车 / 抢夺路过红的士、跑车、三轮车或警车
  - `Q`：在 **陈砺** 与 **林汐** 之间切换主控
  - `E`：与路人/大排档老板（吃鱼蛋粉回血）互动或进入街区通道
  - `Tab`：打开全 244 像素特效轮盘；`M`：切换四大九龙街区或载入自定义写实背景
